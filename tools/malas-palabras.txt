# Lista de palabras que el chat enmascara con asteriscos (*****).
# - Una por línea. Las líneas que empiezan con # son comentarios.
# - Escríbelas en minúscula. Los acentos no importan (cabrón = cabron), la ñ sí (coño ≠ cono).
# - Una * al final significa "y todo lo que empiece así" (puta* cubre puta, putas, putada, putazo…).
# - Se detectan también trucos comunes: mayúsculas, letras repetidas (puuuta), números por letras (m1erda),
#   @ y $ por letras (c@brón) y letras separadas (p u t a).
# - Para agregar o quitar palabras: edita este archivo y ejecuta `node tools/build-worker-data.mjs`, luego sube la web.
# - Palabras que NO deben bloquearse aunque empiecen igual: ver SAFE_WORDS en el final de este archivo (líneas con "ok:").
